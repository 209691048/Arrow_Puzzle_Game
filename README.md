# 一箭又一箭 —— Arrow Puzzle Game

## 一、项目简介

本项目是一款基于 Python 和 Pygame 开发的箭头解谜小游戏。

玩家需要按照箭头当前的指向点击箭头。当箭头的飞行路径上没有其他箭头阻挡时，箭头会沿自身指向飞出游戏区域并消失；如果飞行路径被其他箭头阻挡，则本次点击失败，箭头不会消失，同时扣除一次错误次数。

玩家需要合理安排箭头的点击顺序，将关卡中的所有箭头清除，从而完成关卡。

本项目目前包含 3 个可正常通关的关卡，并在游戏启动时自动进行关卡可解性检查，确保每个关卡至少存在一种通关方案。

---

## 二、项目功能

### 1. 箭头点击与飞出

点击箭头后，程序会检测箭头指向的飞行路径：

* 路径畅通：箭头沿自身指向飞出并消失
* 路径被其他箭头阻挡：箭头不会飞出
* 被阻挡的箭头会短暂变红，提供视觉反馈
* 点击被阻挡的箭头会扣除一次错误次数

### 2. 箭头飞行动画

当箭头可以正常飞出时，箭头会沿着自身的指向移动到游戏区域外。

箭头的移动方向与箭头图形的指向保持一致，从而增强游戏的操作反馈和动画效果。

### 3. 关卡系统

游戏目前包含 3 个独立关卡。

每个关卡拥有不同的箭头布局，玩家需要通过合理安排点击顺序完成关卡。

程序启动时会自动对所有关卡进行可解性检查。

### 4. 关卡可解性检查

程序内部实现了关卡求解检测机制。

游戏启动时会检查每一个关卡是否至少存在一种完整的通关方案。

示例输出：

```text
========== 关卡可解性检查 ==========
第 1 关：√ 存在通关方式
第 2 关：√ 存在通关方式
第 3 关：√ 存在通关方式
==================================
```

如果某个关卡不存在通关方案，程序会在启动时发现问题，从而避免出现无法完成的关卡。

### 5. 错误次数系统

玩家在游戏中拥有有限的错误次数。

当点击一个被其他箭头阻挡的箭头时：

1. 箭头保持原位置
2. 箭头变红进行提示
3. 错误次数减少 1 次

当错误次数耗尽后，当前关卡失败，并可以重新开始游戏。

### 6. 游戏状态

游戏包含以下主要界面：

* 开始界面
* 游戏界面
* 关卡成功界面
* 游戏失败界面

同时提供重新开始和返回主页等功能。

### 7. 背景音乐

游戏加入了循环播放的背景音乐。

音乐资源文件位于：

```text
assets/background_music.wav
```

## 三、游戏规则

玩家需要点击箭头，使箭头沿着自身的指向飞出游戏区域。

### 情况一：箭头前方没有阻挡

```text
点击箭头
    ↓
检测飞行路径
    ↓
没有其他箭头阻挡
    ↓
箭头沿自身指向飞出
    ↓
箭头消失
```

### 情况二：箭头前方存在阻挡

```text
点击箭头
    ↓
检测飞行路径
    ↓
发现其他箭头阻挡
    ↓
箭头变红
    ↓
箭头保持原位置
    ↓
错误次数 -1
```

玩家需要根据当前箭头的位置和方向，合理选择点击顺序。

## 五、安装项目

### 1. 克隆项目

在终端执行：

```bash
git clone https://github.com/209691048/Arrow_Puzzle_Game.git
```

进入项目目录：

```bash
cd Arrow_Puzzle_Game
```

### 2. 创建 Python 虚拟环境

```bash
python3 -m venv venv
```

### 3. 激活虚拟环境

macOS / Linux：

```bash
source venv/bin/activate
```

Windows：

```bash
venv\Scripts\activate
```

### 4. 安装项目依赖

```bash
pip install -r requirements.txt
```
